# عمرو عصام هاشم محمد

صفحة شخصية بخلفية سوداء، وصورة في الأعلى، والاسم العربي أسفلها بحركة صعود وهبوط وتبديل تلقائي بين عشرة خطوط عربية.

## إضافة الصورة
ضع الصورة الشخصية في المسار `assets/omar.jpg` داخل المستودع. يجب أن يكون اسم الملف `omar.jpg` بالضبط حتى تظهر الصورة في الصفحة.

## المعاينة
افتح `index.html` محليًا أو انشر المستودع عبر خدمة استضافة صفحات ثابتة.
